# Gaúchos X Japoneses: Poesia
*O mundo é particionado em duas categorias: **Gaúchos** e **Japoneses**. Pela própria definição, não existe intersecção*

Este é um sistema de agentes LLM com arquitetura de roteamento, cujo objetivo é criar versões de poesia como escrita por gaúchos ou então como escrita por japoneses. Cada um dos dois terá seu agente poeta próprio. Além deles, teremos um agente crítico que deve realizar uma análise comparativa de cada par de poesias criado.

*Se uma coisa é **gaúcha**, então ela não é **japonesa**. Se uma coisa é **japonesa**, então ela não é **gaúcha***
